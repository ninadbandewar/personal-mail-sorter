Desktop email organisation

Local Mail Sorter

A desktop application for organising email with configurable categories, user-defined rules and AI-assisted classification. It is designed to run on the user's computer and connect to email accounts that the user chooses to authorise.

How it works

When a user connects a Gmail account, Local Mail Sorter uses Google's Gmail API to retrieve the email information needed for classification and, when requested, organise messages using Gmail labels and mailbox actions. The user remains in control of the connected account and the actions performed.

AI-assisted classification is performed using the model service configured by the user. In the standard local setup, the application connects to an Ollama service running on the same computer. If the user changes that endpoint or uses another service, email content may be sent to that configured service for processing.

Local processing and control

Application settings, classification history and learning feedback are stored in the local application data directory. The user is responsible for protecting access to that computer and its local files.

Google account access

Gmail access is granted through Google's OAuth consent process. Users can review or revoke that access from their Google Account security settings.

Privacy Policy

Local Mail Sorter is an independently maintained desktop application. This website provides information about the application; it does not host the application or users' email data.
